# ぷらとん / platon-index

OCIとAIで相棒づくり中のインフラエンジニアです。
クラウドの設計・構築が好きで、勉強したことや作ったものを発信しています。

## 作っているもの
- **デスクトップ相棒**：デスクトップに常駐して、声で話しかけてくれるAIの相棒（Python / PyQt6 / VOICEVOX）
- **ルーティン管理アプリ**：毎日のルーティンをこなすと相棒が育つスマホアプリ（Expo / React Native）
- **トリポデス**：ナレッジベースをもとに、3人のキャラが議論して意見をくれる仕組み（Claude Code）

アイコンは相棒の「繰瀬アイ」です。

## 勉強中
- OCI（Oracle Cloud Infrastructure）
